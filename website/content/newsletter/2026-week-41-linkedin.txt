📝 Envoy Addresses Critical TLS Memory Allocation Vulnerability

This week, several Envoy releases (v1.39.2, v1.38.5, v1.37.7, v1.36.11) included fixes for CVE-2026-35189. This vulnerability in BoringSSL could lead to excessive memory allocation when parsing specific certificate types, potentially affecting proxy stability.

🚀 Key Releases

Envoy v1.39.2, v1.38.5, v1.37.7, v1.36.11
  Multiple Envoy patch releases updated BoringSSL to address CVE-2026-35189. This resolves an issue where parsing certificates with nameRelativeToCRLIssuer CRL Distribution Points could cause excessive memory allocation.

OpenTelemetry Collector v0.162.0
  This release introduces a breaking change: generated processor lifecycle tests now assert that the processor propagates the incoming context unchanged by default. This behavior can be disabled with skip_context_propagation: true.

Prometheus v3.13.4
  A security fix updates google.golang.org/grpc to v1.83.1 to mitigate HTTP/2 DATA frame fragmentation memory exhaustion (GO-2026-6348). The UI also received updates for vulnerable npm dependencies.

Podman v6.1.3 and v5.8.8
  These releases address CVE-2026-94603. This vulnerability allowed a podman run command on a checkpoint image (identified by io.podman.annotations.checkpoint.runtime.name annotation) to disable all sandboxing mechanisms.

K3s v1.37.1+k3s1, v1.36.5+k3s1, v1.35.9+k3s1, v1.34.12+k3s1
  K3s updated Kubernetes to v1.37.1, v1.36.5, v1.35.9, and v1.34.12 respectively. Releases v1.35.9+k3s1 and v1.34.12+k3s1 include an upgrade to Traefik chart v40.x, which changes the ingress-nginx provider name from kubernetesIngressNginx to kubernetesIngressNGINX, requiring configuration adjustments.

Kustomize v5.8.2
  This release adds kustomize edit add configuration and kustomize edit remove component commands. The built-in OpenAPI schema is now loaded from a pre-compiled bundle.
