## 👋 Welcome

This week in Cloud Native saw a strong focus on security, with numerous projects releasing updates to address vulnerabilities and enhance compliance. The ecosystem continued to advance in AI and agentic computing, marked by significant project donations to the CNCF and the introduction of new open-source tools for agent development, testing, and orchestration. Additionally, a key configuration management tool reached a major milestone with its v1.0.0 release.

## 📰 This Week in Cloud Native

### AI & Agentic Computing Advancements
This week saw significant developments in the management and deployment of AI agents within cloud native environments. Google announced the donation of **Agent Substrate** and **gVisor** to the CNCF. Agent Substrate is designed for managing agent-like workloads securely at scale, while gVisor provides a code sandbox for untrusted AI agents, enhancing isolation and security.

New open-source tools emerged to support the agentic workflow. **Nomos**, a Go harness, was introduced to prevent coding agents from "cheating" on tests, focusing on verifiable agent output. **Gauge**, an open-source CLI, aims to recursively improve documentation for coding agents. **KeepPlain** helps developers understand agent-written code by saving agent sessions and linking them to Git blame. For agent orchestration, **Rivet** was released, focusing on scaling agentic workloads on S3. Other new tools include **Fluxcut-plugin** for creating product videos with AI agents, **NotBot** as an AI-powered financial news analyzer, and **AI Gude** for generating daily podcasts from news feeds. The **LDraw-mecha** project demonstrated AI agents inferring Lego mechanisms and animating them. The **OpenKruise Agents v0.6.0** release also focused on sandbox security and automation for agents. Discussions also covered strategies for faster LLM inference startup and research into whether code knowledge graphs improve coding agent performance, with one study finding no clear gain.

### Security & Compliance Updates
Security remained a central theme across the cloud native landscape. Numerous projects, including gRPC, OAuth2 Proxy, Kuberhealthy, and Trivy, released updates that often included Go toolchain bumps (e.g., to Go 1.26.10 or 1.27.3) and fixes for various CVEs. Specific security enhancements were noted, such as **Kubevela v1.11.1** guarding workflow HTTP against SSRF vulnerabilities and **Hive** implementing file access limits for CLI-memory drains to prevent unauthorized host path access.

The OpenSSF held its Community Day Europe 2026, emphasizing systemic security and operational resilience in open source. **Sylva**, an open-source project, detailed its journey with OpenSSF, leveraging tools like Sigstore, SLSA, Scorecard, and Best Practices badges for supply chain security. **Kubescape** completed all six Security Slam badges with OpenSSF, demonstrating a commitment to strengthening its security posture. Discussions also highlighted the importance of addressing security vulnerabilities in widely used open-source components like PHP and ensuring accurate Software Bill of Materials (SBOMs), even for complex build graphs like Swift. The **Amutable Foundations Linux** project introduced a system where server boot chains and configurations can be proven with TPM-signed measurements, enhancing trust in Linux clusters. Concerns were also raised regarding AI agents potentially exploiting Docker group root access. **SPIFFE/SPIRE v1.16.0** introduced experimental support for WIT-SVIDs and a KMIP KeyManager plugin, expanding identity and key management capabilities.

### Cloud Native Ecosystem & Tooling
The cloud native ecosystem saw a significant milestone with the release of **kpt v1.0.0**, marking a mature step for the configuration management toolchain. **Lima v2.3.0** expanded its capabilities, adding experimental support for the HCS driver on Windows, allowing host block devices to be attached to VZ guests on macOS, and introducing experimental virtual networks on Linux.

Several new open-source tools were showcased this week. **K8sman** emerged as a native Kubernetes IDE. **DevBox** was open-sourced by RudderStack as an engineering harness. **Hyperbutler** offers a Docker-on-Windows solution without requiring WSL. **FELF** provides a method for creating AppImage-like single binaries without FUSE, root, or a runtime. In workflow management, **Waymark** was introduced as a workflow engine that compiles jobs rather than replaying them. Other tools include **MxRaven** for programmable email infrastructure and **Enmetu** for Git auto-commits that handle conflicts. In education, **Nextcloud** partnered with Ionos to launch an open-source educational platform for schools. The community also discussed the need for **OpenTelemetry** to instrument agent memory, aiming for better observability of agentic workflows.

### Sustainability Initiatives
The CNCF reflected on its recent Sustainability Month, sharing learnings about integrating environmental considerations into cloud native practices. The **Chantico** project continued to advance in sustainability, with its latest releases introducing a stress test for custom resource limits, replacing `resourceIds` with `additionalLabels` on `PhysicalMeasurement`, and enhancing configuration for watching and managing measurement devices across namespaces. These updates provide further technical mechanisms for measuring and managing the environmental impact of cloud native deployments.
