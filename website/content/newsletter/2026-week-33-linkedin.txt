🛣️ Gateway API v1.6 Graduates TCPRoute and UDPRoute to Standard

Gateway API v1.6 has been released, marking TCPRoute and UDPRoute resources as Standard. This graduation signifies stability and readiness for broad adoption of these APIs for traffic routing within Kubernetes clusters.

🚀 Key Releases

*   k3s v1.36.3+k3s1 (and earlier versions like v1.35.7+k3s1, v1.34.10+k3s1, v1.33.13+k3s2) upgrades the bundled Traefik chart to v40.x. This update includes a breaking change where the Traefik provider name for ingress-nginx migration changes from `kubernetesIngressNginx` to `kubernetesIngressNGINX`.
*   cosign v3.1.3 and v2.6.5 were released, resolving GHSA-fx35-mq7g-6g98. This security fix addresses a verification bypass vulnerability that could occur by using an unexpected public key in a legacy bundle format.
*   opentelemetry-collector v0.158.0 introduces a new `processor/queuebatch` component. This processor is designed to replace the legacy `batchprocessor` functionality for queueing and batching telemetry data.
*   inspektor-gadget v0.55.0 adds initial support for GPU telemetry. This release includes a userspace daemon, `gpu-ebpf-bridge`, which publishes GPU telemetry data through pinned BPF maps.
