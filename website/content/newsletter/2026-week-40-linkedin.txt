🛡️ Containerd Releases Address CVE-2026-53493
Multiple containerd versions, including v2.4.1, v2.3.6, v2.2.9, v2.0.13, and v1.7.36, were released this week. These patch releases incorporate a security fix for CVE-2026-53493, addressing a vulnerability within the container runtime.

🚀 Key Releases
*   containerd: Versions v2.4.1, v2.3.6, v2.2.9, v2.0.13, and v1.7.36 were released. Each includes a security fix for CVE-2026-53493.
*   KEDA v2.21.0: This release introduces three breaking changes. Users upgrading from KEDA 2.20 are advised to review the migration guide.
*   kubewarden-controller v1.38.2: Includes breaking changes and security fixes. A notable change is the addition of memory bounds and the replacement of a denylist with an allowlist for namespaced policies.
*   OPA v1.21.0: This version features improved rule indexing and recursion checks. It also includes a breaking change where YAML is now parsed against the 1.2 core schema.
*   kube-ovn v1.16.8: This patch fixes VIP reconciliation and VMI migration handling. It reduces IPv6 neighbor solicitation flooding in underlay networks and updates containerd to v2.2.9 to address CVE-2026-53493. Support for image pull secrets for VPC NAT gateway pods was also added.
