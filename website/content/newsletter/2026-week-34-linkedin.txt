☁️ Cloud Native Buildpacks Graduates from CNCF

The Cloud Native Computing Foundation announced the graduation of Cloud Native Buildpacks. This signifies the project's maturity and widespread adoption as a standard for transforming application source code into container images.

🚀 Key releases

cluster-api v1.14.0: This release updates Kubernetes version support, with management clusters now supporting v1.33.x through v1.36.x and workload clusters supporting v1.31.x through v1.36.x. The project also transitioned to using Go 1.26.

antrea v2.7.0: This release changes default behavior by authenticating and encrypting Antrea Agent gossip traffic. This prevents unauthorized hosts from influencing the cluster membership state, impacting features like IP ownership for Egress and ServiceExternalIP.

containerd v2.3.4: The default behavior for checkpoint restore in CreateContainer has been changed to disabled. Re-enabling this functionality now requires explicit configuration via the enable_experimental_restore_via_create option.

podman v5.8.6: This patch release addressed CVE-2026-19730. The vulnerability involved the podman quadlet install --replace command not truncating the file being replaced, which could result in old data remaining if a longer file was replaced by a shorter one.

longhorn v1.12.1: This release introduces new features including V2 Data Engine fast volume cloning and experimental storage sharding capabilities.
